Buy minutes once. Spend them only while the meter runs.

TimeGate is DataRail's prepaid time system. People pay through Stripe or Square and the minutes land on their account. They spend them on a device that stays locked until someone starts a session on it, or inside a datarail service that only answers during a paid session. An admin sets what a minute costs, and the server, not the device, keeps the time.

How it works

From a payment to an open gate

Money and time travel on separate rails. The processor confirms a payment to the server directly, the server credits the minutes exactly once, and a gate stays open only while the server keeps hearing from the session.

Gates

Two kinds of gate, one balance

Everything a person buys goes into one balance of minutes. An admin decides which gates exist and how fast each one spends time, so an hour on one can cost more than an hour on another.

Device gate

A machine that stays locked until you start

An enrolled Windows, Linux or Android device boots into a lock screen. Someone signs in and starts a session; the screen opens and a small meter stays on top. When they stop, run out, or the connection goes quiet for 90 seconds, it locks again and signs them out.

On Android set up as a dedicated device, the operating system holds the lock. On Windows and Linux the app pairs with the system's own kiosk mode.

Service gate

A datarail app that answers only while you're paid up

A datarail service, named by the same app id the Library uses (Trends, GhostSignal, and so on), asks TimeGate before it answers. The person's app carries a gate token for the running session; the service checks it with its own credential and gets back yes or no, and how much time is left.

A passing check keeps the session billed. A token for a different app is refused without touching the session it belongs to.

Use cases

What it's for

Anywhere time is the thing being sold, and the place selling it shouldn't have to stand there with a stopwatch.

  1. 01 · DEVICE Computers by the minute A library, makerspace or café lends a PC that unlocks for whoever has time on their account, and locks the moment it runs out.
  2. 02 · DEVICE Tablets and phones on loan Android devices set up as kiosks, so the operating system keeps people at the lock screen until they start a session.
  3. 03 · SERVICE Pay as you go, no membership Try a members-only datarail feature, such as the Trends live dashboard, for an hour instead of joining for a month.
  4. 04 · SERVICE Timed play at events Sell play time at the door for a GhostSignal hunt or a pop-up station. Every session stops when its time is up.
Guarantees

Rules the server keeps

Each of these is held by the server and its database, and each has tests that try to break it.

  • Only the processor's signed word adds time.The browser coming back from checkout never does, and neither does anything the app claims.
  • A payment is credited once.However many times the processor calls, and in whatever order its messages arrive.
  • The price is fixed when you start paying.Changing prices later never touches time already bought or already quoted.
  • Only the server's clock counts.Time is billed to the device's last check-in. Silence is never billed, and changing the device's clock changes nothing.
  • Devices fail closed.A device that stops hearing from the server locks itself within 90 seconds, even with no connection.
  • History is never edited.The ledger and the admin log only grow. A correction is a new entry, with the admin's reason attached.
The app

One app for members, admins and kiosks

Built with Flutter for Windows, Linux and Android, in the same style as this site, circuit rails included. Members buy time and run sessions; admins set prices, gates and devices; an enrolled device boots straight into its lock screen.

Status

Where it stands

In development. The server, the app and their tests are built, and it has not taken a real payment yet. Before it does: a full run through each processor's test mode, a refund policy, and a decision on how the Android app is distributed, because Google Play has its own rules for selling digital time.
